# 心奇学习官网

个人学习应用链接聚合站，纯前端单文件应用，由 GitHub Pages 托管。

在线访问：https://52nomis9.github.io/xinqi-site/

## 文件
- `index.html` — 网站主程序（含全部逻辑与内容数据）
- `avatar.png` — 头像图片
- `music.mp3` — 背景音乐

## 更新内容
打开在线地址 → 左上角「⚙️ 设置」→ 输入管理员账户密码 → 修改内容 → 「🚀 发布到线上」。
发布需 GitHub 访问令牌（建议仅授权本仓库、仅 Contents 读写权限的 Fine-grained Token），令牌只保存在发布者自己的浏览器中。

## 说明
本仓库与网站为个人家庭学习用途。
